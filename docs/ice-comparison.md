# Ice 与 wd-ice-bar：实现与能力对照

## 共同基础

两者都在 macOS 菜单栏中放置自己的控制项与分隔项，通过扩大分隔项宽度，将一侧第三方状态栏图标挤出可视区域；再从 WindowServer 读取对应窗口，取得截图、窗口 ID、进程和坐标。

| 能力 | Ice | wd-ice-bar |
| --- | --- | --- |
| 隐藏机制 | 宽分隔项改变菜单栏排版 | 同样使用透明宽分隔项（长度 `10_000`） |
| 图标副本 | 读取菜单栏窗口并渲染副本 | 缓存窗口截图，在 `NSPanel` 中渲染副本 |
| 左键/右键 | 通过原生事件路由操作真实图标 | 临时恢复原生项，再转发左键或带 WindowID/PID 的右键 |
| 布局编辑 | Layout Bar 拖拽副本并移动真实图标 | “调整菜单显隐”中跨蓝线拖拽副本，移动真实图标跨分隔项 |
| 权限 | 屏幕录制与辅助功能 | 同样需要屏幕录制与辅助功能 |

## wd-ice-bar 当前交互

1. 左键顶部控制图标：展示隐藏图标栏。
2. 左键副本：恢复对应原生图标并转发左键。
3. 右键副本：恢复对应原生图标并转发右键，打开原应用菜单。
4. 右键顶部控制图标：可调整菜单显隐、打开系统菜单管理、刷新应用、切换图标、设置开机启动或退出。
5. 调整菜单显隐：蓝线左侧代表原生显示，右侧代表隐藏。仅跨蓝线的项目会触发真实原生 `⌘` 拖拽；完成后编辑栏保持打开，方便连续调整。

## 核心差异

Ice 是完整产品，拥有三段分组、热键、悬停、自动显示、更多布局/多显示器设置、导入导出、更新与更完整的兼容性处理。

wd-ice-bar 只专注于两段显隐、展开栏、原生左右键转发和跨分隔线调整。它不尝试同步同一侧全部图标的任意排序，以避免不可移动的系统项中断显隐操作。

## 技术边界

窗口截图使用屏幕录制权限；事件转发与 `⌘` 拖拽使用辅助功能权限。菜单栏项的精确枚举依赖私有 CGS/WindowServer 接口：如果该接口在未来 macOS 中不可用，应用仍能启动，但隐藏项识别、截图、转发和拖拽会失效。
