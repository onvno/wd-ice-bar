# Ice 与 TopShelfLite：实现与能力对照

## 目标

两者都通过 macOS 菜单栏中的控制项和分隔项，把第三方状态栏图标划分为“显示”和“隐藏”两组。TopShelfLite 是当前工作区中的轻量实现，目标是只保留隐藏、展开、原生排序、图标和退出等核心功能。

## 共同实现方式

| 能力 | Ice | TopShelfLite |
| --- | --- | --- |
| 状态栏分组 | 使用自己的可见控制项和隐藏分隔项 | 使用 `▦` 控制项和透明宽分隔项 |
| 隐藏机制 | 将隐藏分隔项扩展到很大宽度，挤出一侧图标 | 同样将分隔项长度设为 `10_000` |
| 图标采集 | 读取 WindowServer 菜单栏窗口并缓存截图 | 使用同类 WindowServer 菜单栏窗口读取并缓存截图 |
| 展开栏 | Ice Bar 渲染图标副本 | `NSPanel` 渲染图标副本，并转发点击 |
| 原生排序 | 用户按住 `⌘` 拖动真实状态栏图标跨过分隔项 | 同样在“调整顶部图标”模式下使用原生 `⌘` 拖动 |
| 权限 | 屏幕录制用于抓取，辅助功能用于事件操作 | 屏幕录制用于抓取，辅助功能用于副本点击转发 |

## TopShelfLite 当前交互

1. 点击 `▦`：展开隐藏图标栏。
2. 点击原生菜单栏任意位置：展开栏收起。
3. 右键 `▦`：可进入原生调整模式、更换图标、打开“系统设置 → 控制中心”或退出应用。
4. 调整模式：原生图标临时恢复；按住 `⌘` 将真实图标拖到分隔标记两侧，决定其之后显示或隐藏。

## Ice 更完整的能力

Ice 在同一基础机制上增加了较完整的产品层：

- Layout Bar：专门的图标布局界面，可拖动副本并由 Ice 重排真实图标。
- 三段分组：可见、隐藏、始终隐藏，而非仅两组。
- 多种触发方式：点击、悬停、热键、临时显示计时器和 Ice Bar。
- 图标/布局设置：更多控制图标、分隔符、主题、间距、位置和多显示器策略。
- 菜单栏项目管理：更完善的项目识别、可移动/不可隐藏项目规则、缓存和重排等待机制。
- 启动登录、更新、诊断、导入导出、快捷键和更广泛的兼容性处理。

## TopShelfLite 目前刻意缺少的能力

TopShelfLite 保持轻量，暂不实现：

- 副本拖拽自动重排真实图标（此前实验版本已回退，稳定性不足）。
- 始终隐藏分组和多段分隔符。
- 热键、悬停、自动显示与计时器。
- 多显示器、主题/间距/布局编辑器等配置。
- 自定义图片图标、导入导出、启动登录和自动更新。

## 后续优先级建议

若要继续提升体验，建议按以下顺序进行：

1. 提升原生调整模式的可见提示与引导；这是最稳定的排序方式。
2. 添加快捷键和临时显示；收益高、实现风险低。
3. 只在完整复用 Ice 的移动验证逻辑后，再引入副本拖拽自动重排。
4. 最后再考虑始终隐藏分组、多显示器和更丰富的外观配置。
