# TopShelfLite

一个独立、轻量的 macOS 状态栏应用原型：

- 透明分隔项把其右侧的状态栏图标推到屏幕外；
- 点击 `▦` 图标，在菜单栏下方渲染右侧隐藏状态图标的截图；
- 不包含布局编辑器、主题、快捷键或自动隐藏策略。

## 运行

在 Xcode 中直接打开 `Package.swift`，运行 `TopShelfLite` target；或执行：

```bash
./scripts/build-app.sh
open build/TopShelfLite.app
```

首次运行后，到“系统设置 → 隐私与安全性 → 屏幕录制”允许 TopShelfLite。构建脚本会用本机的 Apple Development 证书签名，macOS 才能跨重建稳定识别应用；切换到这版签名后需要重新授权一次，退出并重开即可。右键 `▦`，选择“调整顶部 / 隐藏图标”，然后按住 `⌘` 拖动自定义栏中的蓝色分隔标记：左侧会置顶到 TopShelfLite 的小图标栏，右侧保持隐藏。编辑器只使用分隔符左侧的缓存图标，不会混入日期、控制中心等系统项。若要从展示栏直接点击原图标，还需允许 TopShelfLite 使用“辅助功能”。

若需指定其他证书，可在执行脚本前设置 `TOPSHELF_SIGNING_IDENTITY`。

## 当前边界

这是第一版可用骨架，面板中的图标是忠实截图。点击时应用会短暂显示原状态栏项并发送一次原生左键事件；部分带有自定义事件处理的第三方图标可能仍需单独适配。
